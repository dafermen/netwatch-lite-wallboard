## Limits And Recovery

Only `app/` and package layout metadata are hashed, not operator JSON, local pages, docs/licenses, or browser data. Reparse-point payloads are conservatively refused, including some cloud/virtual-storage placeholders; use an ordinary local folder. Direct payload execution bypasses the gate. Windows/Framework/WebView2 and changes after verification are outside the guarantee. Replacing the whole launcher/reference can bypass it; this is not publisher signing.

No configuration repair, deletion, auto-download, manifest regeneration on failure, or browser-profile reset occurs. Restore from a complete trusted ZIP into a new folder and preserve operator data. `MSB3277` remains a known build warning. See [Portable integrity](../PORTABLE_INTEGRITY.md) for exact behavior and diagnostics.
