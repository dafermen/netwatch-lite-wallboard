## Safety And Limits

- Existing generated version outputs are refused, not erased; old `publish/` packages and source JSON stay untouched.
- Package checks edit only disposable copies under ignored `artifacts/verification/`. The application probe does not save JSON or start WebView2.
- JSON and local pages live at the root; runtime files live in `app/`. The layout marker is not a cryptographic manifest.
- The root launcher only forwards arguments; it does not perform per-file integrity validation or establish publisher authenticity.
- WebView2 and Windows components remain external; bundled .NET patches require a new package.
- `MSB3277` WindowsBase/WebView2 remains a known warning.
- Full acceptance, broad fuzzing/mutation baseline, clean-device compatibility, and long production runs are not claimed complete.
