## Known Limits

The package smoke test also identified a clipped Delete command in small Settings windows. The editor now supports vertical scrolling without horizontal clipping; its regression test verifies the command is fully reachable at minimum size.

- `MSB3277` concerning WebView2/WPF and WindowsBase remains a known build warning.
- Estimated combined process working sets may count shared physical pages more than once.
- The candidate requires .NET 10 Desktop Runtime; .NET 8 alone is insufficient.
- The long-session tests and complete release checklist are required before promotion to stable.
