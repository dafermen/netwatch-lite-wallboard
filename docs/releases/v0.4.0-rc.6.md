## Delivery Procedure And Remaining Gates

Build from the reviewed clean source commit; run the complete local desktop suite, guarded build, audit, documentation/script/whitespace checks and publisher guards. `scripts/publish-portable.ps1` must test the exact ZIP before retaining it under `artifacts/packages/`, alongside the matching extracted folder under `artifacts/portable/`. Exercise the extracted package with isolated JSON/browser data, never operator profiles.

Push the source without generated artifacts, wait for CI, then use `scripts/publish-prerelease.ps1` in **Draft** mode with the same ZIP/sidecar and full source SHA. Download and compare both assets. Never rebuild/reupload an existing version to change embedded docs; a later documentation-only handoff commit may record final evidence on main while the draft and ProductVersion continue pointing to the original binary commit.

Production/24-hour, real company-page, real monitor-DPI/other-device and broader fuzz/mutation/E2E acceptance remain required before normal production/stable approval. Public evaluation distribution would still require separate explicit authorization.
